Smart Lease Manager

SmartLease Manager is a web-based property management tool designed for small landlords and property managers. It streamlines two core workflows: maintenance request triage and document verification. Tenants can submit repair requests with descriptions, photos, and a problem category, and the system automatically prioritizes each issue as High, Medium, or Low based on urgency. Managers view a color-coded priority queue so urgent repairs are addressed first. For document verification, tenants upload IDs and proof of income, and the system generates a SHA-256 hash and timestamp for each file, creating a tamper-evident digital receipt. Managers can mark documents as verified, add notes, and view a permanent audit trail that records who verified what and when. Built with PHP, SQL, HTML, CSS, and JavaScript, SmartLease Manager replaces scattered emails and spreadsheets with a centralized, easy-to-use platform that reduces manual coordination and improves tenant satisfaction.
